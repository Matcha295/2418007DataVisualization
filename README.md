# Visualisasi Data Penjualan
Proyek ini dibuat menggunakan Python di Google Colab untuk mengolah dan menampilkan data penjualan dalam bentuk grafik.

Proses
- Membaca data dari file Excel.
- Menghitung GMV dari harga dan jumlah barang.
- Membuat grafik garis untuk melihat penjualan setiap bulan.
- Membuat diagram batang untuk melihat perbandingan penjualan setiap merek.

Tools
- Python
- Pandas
- Matplotlib
- Google Colab
